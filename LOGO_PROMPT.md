## 📐 Что отдавать дизайнеру/себе после генерации

1. **PNG 1024×1024** — для App Store / PWA `icon.png`
2. **PNG 512×512** — для текущего `icon.svg` замена
3. **PNG 192×192** — для Android Chrome
4. **PNG 32×32 favicon** — флэт-версия (Вариант B)
5. **PNG 1200×630 OG** — для соцшеринга, имя `og.png`
6. **SVG vector** (если возможно) — для бесконечной масштабируемости

## 🎨 Цветовая шпаргалка для всех генераций

| Назначение | HEX | Использовать как |
|---|---|---|
| Основной royal | `#034694` | Тело компасной стрелки |
| Тёмный royal | `#0a1f44` | База стрелки, тени |
| Светлый royal | `#1e3a8a` | Градиентные переходы |
| Cream фон | `#fbf7ed` | Светлый фон |
| Dark navy фон | `#05122b` | Тёмный фон |
| Neon cyan | `#00f5ff` | **Только** свечение на кончике стрелки |
| Glass белый | `rgba(255,255,255,.62)` | Стеклянная сфера |

## ⚠️ Что не должно появиться в результате

- ❌ Реалистичный физический компас с N/S/E/W буквами
- ❌ Слово «Atlas» внутри иконки (только в wordmark-варианте)
- ❌ Радужные градиенты, неоновый фон
- ❌ Дополнительные элементы (планеты, карты, звёзды)
- ❌ Острые углы, агрессивная геометрия
- ❌ Тёмные тени снизу (плоский float как у iOS, без drop-shadow)
- ❌ Дополнительный текст / подписи / номера версии

## 🚀 Куда дальше отдать результат

После того как сгенерируешь:
1. Скачай PNG/SVG
2. Положи в папку `/personal-planner/` вместо текущего `icon.svg`
3. (опционально) Создай `icon-512.png` и `icon-192.png` и обнови `manifest.json`:
   ```json
   "icons": [
     {"src": "icon-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any maskable"},
     {"src": "icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any maskable"}
   ]
   ```
4. Залей через GitHub upload → done
