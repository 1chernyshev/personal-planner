# 📓 Личный планер

Календарь · Привычки · Задачи · Пространство (Notion-like) · Напоминания — всё в одном HTML-файле. Никакого бэкенда, все данные хранятся в браузере.

## Что внутри

- **📅 Календарь** — месяц / неделя / день. Кликом по ячейке создаёшь событие.
- **🔥 Привычки** — расписание (каждый день / выбранные дни недели / каждые N дней), период, напоминания, streak-счётчик.
- **✓ Задачи** — несколько списков, подзадачи, теги, приоритеты, дедлайны, напоминания.
- **📓 Пространство** — Notion-like: страницы с вложенностью, блоки (текст, заголовки, чек-листы, цитаты, код, разделители). Inline-редактирование.
- **🔔 Напоминания** — как iPhone Reminders: списки, дата+время, повторы (день/неделя/месяц/год), браузерные пуши.
- **⚙️ Настройки** — категории, экспорт/импорт JSON, экспорт `.ics`, тёмная тема, сброс.

## Запуск локально

Двойной клик по `index.html` — открывается в браузере. Всё.

## Деплой на GitHub Pages

```bash
cd ~/Downloads/personal-planner
git init
git add .
git commit -m "Initial commit"
gh repo create personal-planner --public --source=. --push
gh api -X POST repos/{owner}/personal-planner/pages -f source[branch]=main -f source[path]=/
```

Через 1–2 минуты сайт доступен по адресу:
`https://<твой-username>.github.io/personal-planner/`

## Уведомления

Браузерные пуши работают **только пока вкладка открыта**. Для фоновых нужен либо мобильный wrapper (PWA + Service Worker + push-сервер), либо нативное приложение. Для личного планера с открытой вкладкой в фоне — нормально.

## Бэкап

`Настройки → Экспорт JSON` — сохраняет всё одним файлом. Импортом загружаешь на другом устройстве.
