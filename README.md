# 🧭 Atlas

**Держи курс.** Календарь, привычки, задачи, пространство и напоминания — в одном месте. Без подписок. Всё твоё.

## Что внутри

- **📅 Календарь** — месяц / неделя / день. Полная свобода редактирования.
- **🔥 Привычки** — гибкое расписание (каждый день / по дням недели / каждые N дней), период, напоминания, streak.
- **✓ Задачи** — несколько списков, подзадачи, теги, приоритеты, дедлайны, напоминания.
- **📓 Пространство** — Notion-like: страницы с вложенностью, блоки (текст, заголовки, чек-листы, цитаты, код).
- **🔔 Напоминания** — списки, дата+время, повторы, браузерные уведомления.
- **⚙️ Настройки** — категории, экспорт/импорт JSON, экспорт `.ics`, тёмная тема.

## Технологии

Чистый HTML + CSS + JavaScript. Никаких сборщиков, фреймворков, бэкенда. Данные — в `localStorage` браузера. Один файл, легко форкается.

## Запуск

Просто открой `index.html` в браузере. Или залей на любой статический хостинг — GitHub Pages, Netlify, Vercel.
